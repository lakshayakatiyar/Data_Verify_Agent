# Data_Verify_Agent

An AI-powered Business Data Verification Agent that analyzes Excel datasets, verifies business information using multiple validation checks, and intelligently classifies records into Real, Needs Review, and Fake categories while generating a structured verification report.

Features & Advantages:-

-> Verifies business data from uploaded Excel files.

-> Validates business name, category, mobile number, email, address, and website URL.

-> Classifies records into Real, Needs Review, and Fake categories.

-> Generates a verification score for each business record.

-> Supports bulk verification through Excel file upload.

-> Automatically creates separate output sheets for verified results.

-> Helps improve data quality by identifying inaccurate or suspicious records.

-> Saves time by automating the business data verification process.

-> Simple, fast, and user-friendly interface with AI-powered analysis.
